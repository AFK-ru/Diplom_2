Diplom Задание 2

Тесты:

test_login_user.py
Тестирует:
1) вход под существующим пользователем
2) вход с неверным логином и паролем

test_create_user.py
Тестирует:
1) создать уникального пользователя
2) создать пользователя, который уже зарегистрирован
3) создать пользователя и не заполнить одно из обязательных полей

test_create_order.py
Тестирует:
1) создание заказа с авторизацией
2) создание заказа без авторизации
3) создание заказа с ингредиентами
4) создание заказа без ингредиентов
5) создание заказа с неверным хешем ингредиентов


Вспомогательные файлы:

api:
base_client.py - хранит шаблоны для формирования базовых запросов к api

order_client.py - хранит методы для оформления заказов

user_client.py - хранит методы для работы с пользователем


data:
urls.py - хранит ссылки на базовую страницу сайта и все необходимые для тестов эндпоинты (ручки)


helpers:
generator.py - генерирует тестовые данные


conftest.py - хранит фикстуры

requirements.txt - хранит библиотеки тестового стенда
